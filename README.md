# JenAiSystems Website

Marken- und Website-Repo für JenAiSystems.

## Marke

- **Name:** JenAiSystems
- **JEN:** Joint Evolution Network
- **Vision:** A world where intelligent systems evolve with us.
- **Mission:** Turning intelligence into action.
- **Prinzipien:** Judgment · Execution · Navigation
- **Claim:** Beyond intelligence. Into action.
- **Leitgedanke:** Intelligence that moves things forward.

## Struktur

- `brand/` – Markenstrategie, Messaging, Sprachleitfaden
- `content/` – Website-Texte
- `src/` – Astro-Website (folgt)
- `public/` – Assets (folgt)
