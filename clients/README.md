# Kunden

Ein Ordner pro Kunde: `antworten.json` (vom Fragebogen) und die daraus erzeugten Dateien.
`beispiel/` ist eine **erfundene** Bäckerei zum Testen und für den Demo-Modus auf der JenAiSystems-Website. Die Telefonnummern und Adressen darin gibt es nicht.
`jenaisystems/` ist der Assistent der JenAiSystems-Website selbst. Alle Angaben stammen von der Website; was dort nicht steht, beantwortet er mit „bitte direkt anfragen“.
Erzeugte Dateien nicht von Hand ändern, sondern `antworten.json` anpassen und `npm run generate -- …` erneut ausführen.
